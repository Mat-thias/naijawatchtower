USSD simulator

This page plays the role of a telecom aggregator. Each press of Dial / Send posts the session so far to POST /ussd (form fields sessionId, serviceCode, phoneNumber, text), via a server-side proxy that adds the shared secret. The raw reply is shown exactly as a phone would receive it, with a character counter that turns red above 160.

  • Try 3 then a unit code to register, 1 to check your unit, 2 to verify.
  • The phone number is hashed on the server and never stored.
  • Real use needs a telecom aggregator, a shortcode and regulatory approval.
